## 三、取证与归因（本轮新发现 · 根因链更新）

| 证据点 | 结果 |
| --- | --- |
| 计量快照 | `data/metrics-usage.json` 已存在（2026-11-21 生成）但 **calls/tokens 全零**——服务曾启动，从未完成一次真实工具调用 |
| ZCode host | 报 **`Server's protocol version is not supported: 2026-07-28`**（ERA_NEGOTIATION_FAILED）——接入断裂 |
| 根因定位 | initialize 响应硬编码 `protocolVersion: 2026-07-28`；host 请求旧版本（如 2025-06-18）并对「服务端改报他版」**不降级兼容**——必须原样回显 client 请求版本 |
| 修复 | **H6 协议协商**（v2.57.0）：initialize 原样回显 client 版本（支持集 2026-07-28/2025-11-25/2025-06-18/2024-11-05）；本地 ZCode 式探测验证回显成功 ✅ |
| 同因旁证 | 用户 ZCode 配置中 zread/web-search-prime/web-reader 亦报同型 ERA_NEGOTIATION_FAILED（第三方服务器同病——非家族独有） |

**归因**：真无流量，但性质与前两轮不同——前两轮为「接入动作未发生」（配置未接）；本轮为「**接入已接但协议协商断裂**」（工具链缺陷）。这是第三类根因，且已在本轮闭环（H6 + 2.57.0）。
