### 2.2 P1-T4b 协同度指标生产端接线（本轮核心增量）

- **新增** [`architecture-kernel/09-可观测性/collaboration-instrumentation.ts`](../../architecture-kernel/09-可观测性/collaboration-instrumentation.ts)：四个零侵入 Proxy 仪表
  - `instrumentIntentGateway`：千行澄清命中（intent=unknown 或置信度 < τ_low，默认 0.6）
  - `instrumentEscalationPolicy`：human-confirm 命中
  - `instrumentComplianceAudit`：traceId 非空命中
  - `instrumentOutcomeLabeler`：学习回流标注即记分子
- **`FamilyMetrics.recordReplay(collected, labeled)`**：复盘覆盖率两端记账——装配层桥接受理记分母、labeler 标注记分子，与 `recordCollaboration` 共用同一张 map
- **装配层自动接线**：`runtime-assembly.ts` 注入 metrics 即完成学习回流两端；千行澄清 / escalation / 审计链由部署侧包装（内核零反向依赖 family-agents）
- **新增** `tests/integration/collaboration-wiring.spec.ts`（8 例，真实网关 / 策略 / 审计验证）
